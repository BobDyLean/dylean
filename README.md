# DyLean

DyLean is a framework for the symbolic analysis of cryptographic protocols in Lean.

With DyLean,
you can specify cryptographic protocols,
write their expected security properties in the symbolic model,
prove that these security properties indeed hold (!),
and check that your protocol specifications capture intended behaviors
(e.g. honest executions or known attacks exist).

**Disclaimer.**
We are actively working on DyLean, expect breaking changes. If you want to use DyLean, please contact us.
